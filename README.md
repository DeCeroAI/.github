# DeCeroAI/.github

Organization-wide files for [github.com/DeCeroAI](https://github.com/DeCeroAI).

- `profile/README.md`: the organization landing page. Banners in `profile/assets/` are generated by `scripts/banner.py` from the deceroai.com fonts (`python scripts/banner.py <path to Website/public/fonts>`, needs fonttools and brotli).
- `SECURITY.md`: the default security policy for every public repository in the organization that has none of its own.
