# Security policy

This policy covers every public repository in the DeCeroAI organization that does not carry its own `SECURITY.md`.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- Preferred: use **Report a vulnerability** on the repository's Security tab (GitHub private vulnerability reporting).
- Or email **michael@deceroai.com** with "Security" in the subject.

Include what you found, the steps to reproduce it, and the impact you expect. You will get an acknowledgement within 3 business days and a status update at least every 7 days until the issue is resolved.

## Scope

In scope: code in the DeCeroAI organization's public repositories. The deceroai.com website is in scope too; report it the same way.

Please do not test against systems you do not own, run denial-of-service tests, or access data that is not yours.
